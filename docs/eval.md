# Evaluation

Figures in the README and on the case page come from these tables. They were measured on 12 November 2026 (Asia/Singapore) on an 8-core CPU (15 GB RAM, no GPU).

**Command:** `python scripts/evaluate.py`

The samples are synthetic surfaces (metal, fabric, stone) generated by `scripts/make_samples.py`: 8 good training images, 6 good test images and 12 defective test images per surface, one defect per defective image. All images are fictional.

## Detection — PatchCore, `wide_resnet50_2`

Image and pixel AUROC, and the flagged-region counts, do not use a language model. A defect is flagged when its score is above a threshold taken from the good training images (highest leave-one-out score). “Top region hits” counts flagged defects whose highest-scoring region overlaps the ground-truth mask.

The accuracy figures below are from the Hugging Face describer run. The **timings** are from a quieter detection-only run on a fresh clone of the same machine ([`eval-detection.md`](eval-detection.md)); an earlier run that also described regions was slower because the box was shared, and those times are not used here. See [`EVAL_NOTES.md`](EVAL_NOTES.md).

| Surface | Train | Test good | Test defect | Image AUROC | Pixel AUROC | Flagged defect | Flagged good | Top region | Fit (s) | s / image |

Backbone: `timm/wide_resnet50_2.tv_in1k`. PatchCore is implemented in this repository from the paper (mid-level patch features, greedy coreset memory bank, nearest-neighbour distance).

## Region labels — Qwen3-VL-2B, Hugging Face backend

Label accuracy is scored only on regions that were flagged and that hit the mask. Raw table: [`eval-hf.md`](eval-hf.md), [`eval-hf.json`](eval-hf.json).

| Surface | Label accuracy | Notes |

Describer: `Qwen/Qwen3-VL-2B-Instruct`. Region labels are a description to help review, not a classification you can rely on.

An API-backend describer run (same 2B model as a Q4_K_M GGUF) is in [`eval-api.md`](eval-api.md). A DINOv2 backbone run is in [`eval-dino.md`](eval-dino.md). Neither is the headline.
